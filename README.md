An entry for the [make.fun](https://make.fun) bounty
"One-Sentence Absurd Invention Pitch".

`main.py` writes one sentence pitching a ridiculous invention — a desk lamp
that files a formal noise complaint against a leaf blower — to
`/output/entry.txt`. The gate allows at most 220 characters.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
